## 如何运行

用 Godot 4.7.2 打开项目根目录的 `project.godot`，按 F5。地图点击第一关，阅读目标和 Tips，点击 Start Challenge。Windows/Linux/Mac 构建位置及校验值见 `BUILD-VERIFICATION.md`。

- WASD 游动；空格开关灯；R 从当前锚点重试。
- Escape 暂停；暂停时 Q 回地图。
- M 音乐开关；N 音效开关；F1 调试信息。
- 正常游玩不显示时间。通关才展示用时和解锁下一关。
- 地图保存解锁和个人最快时间。重新挑战整关清空该次分数，锚点重试只丢本段未保存奖励。

1. 新玩家三关能否在5–10分钟内理解并完成、是否有趣；需一次真实试玩。
2. 第三关灯光引诱是否成为玩家主动采用的策略。当前不宣称“不引诱绝对无法通过”。
3. 实際画面/鼠标操作/混音试听。编辑器能读取，但本轮自动运行输入未成功打开游戏窗口。
