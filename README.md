# Ballast

Local development prototype for CSCI 5999B Project 1.

Engine: Godot 4.7.2 stable, GDScript, Compatibility renderer.

Open `project.godot` with Godot and press F6 on `scenes/TestRoom.tscn`, or F5 for the main menu.

Status: implementation in progress. No human playtest or platform validation is claimed yet.
